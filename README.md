# 📚 Beecrowd Exercises

This repository contains solutions to programming exercises from **Beecrowd**, focused on improving logic and problem-solving skills using **Java**.

---

## 🎯 Purpose

The main goal of this project is to practice:

* Programming logic
* Problem-solving skills
* Algorithm development
* Java syntax and structure

---

## 🛠️ Technologies Used

* Language: Java
* Platform: Beecrowd

---

## 📂 Structure

The project is organized by exercises, where each file represents a solved problem.

```
/exercises
  ├── problem1.java
  ├── problem2.java
  ├── problem3.java
  └── ...
```

---

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/beecrowd-exercises.git
cd beecrowd-exercises
```

2. Compile a file:

```bash
javac fileName.java
```

3. Run the program:

```bash
java fileName
```
